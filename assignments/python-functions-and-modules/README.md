# 📘 Assignment: Python Functions and Modules

## 🎯 Objective

Write reusable Python functions and organize related logic into separate modules. This assignment helps students practice breaking larger problems into smaller, clearer pieces and building programs that are easier to read and maintain.

## 📝 Tasks

### 🛠️ Create Reusable Functions

#### Description
Write a Python program that uses functions to organize repeated logic instead of copying code multiple times.

#### Requirements
Completed program should:

- Define at least three functions with clear names and specific purposes.
- Use parameters and return values to pass information between functions.
- Avoid repeating the same code in multiple places.
- Call the functions in the correct order to complete the task.

### 🛠️ Build a Small Utility Module

#### Description
Create a helper module that contains functions related to one theme, such as math, text processing, or user greetings.

#### Requirements
Completed program should:

- Store related functions in a separate file or module.
- Import the module into the main program.
- Use functions from the module to complete a simple project.
- Keep the main code short and focused on program flow.

### 🛠️ Solve a Real Problem with Functions

#### Description
Use functions to solve a small problem that requires repeated calculations or decision-making.

#### Requirements
Completed program should:

- Read input from the user or process predefined data.
- Use functions to handle calculations, validation, or formatting.
- Return useful output that shows the result of the task.
- Include at least one example of a function returning a value.

### 🛠️ Stretch Goal: Add a Module-Based Workflow

#### Description
Organize your code into a more realistic project structure with a main script and helper functions.

#### Requirements
Completed program should:

- Separate logic into a main file and one helper module.
- Use imports so the helper code is reused cleanly.
- Keep naming consistent and readable.
- Explain in comments or a short summary how the modules work together.
