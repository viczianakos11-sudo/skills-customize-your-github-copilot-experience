# 📘 Assignment: Hangman Game

## 🎯 Objective

Build a classic Hangman game in Python using strings, loops, conditionals, and user input. This assignment helps you practice working with word selection, tracking progress, and handling game states.

## 📝 Tasks

### 🛠️ Build the Game Logic

#### Description
Create a playable Hangman game where a player guesses letters to reveal a hidden word before running out of attempts.

#### Requirements
Completed program should:

- Randomly choose a word from a predefined list of words.
- Display the hidden word as underscores, such as `_ _ _ _ _`.
- Allow the player to enter one letter at a time.
- Reveal matching letters in the correct positions.
- Track incorrect guesses and show how many attempts remain.
- End the game when the player correctly guesses the word or runs out of attempts.
- Display a clear win or lose message at the end.

### 🛠️ Improve the User Experience

#### Description
Add a few polished gameplay features so the game feels complete and easy to play.

#### Requirements
Completed program should:

- Prevent duplicate guesses from being counted multiple times.
- Show the letters the player has already guessed.
- Keep the game loop running until the player decides to stop or the game ends.
- Use clear prompts and messages so the user knows what is happening.
